# SQL Learning Journey for Data Analysis 📊✨

This repository contains my hands-on SQL practice while learning SQL for Data Analysis — starting from beginner concepts and slowly moving towards more logical and analytical querying 👩🏻‍💻

Instead of just memorizing syntax, I tried to understand SQL like conversations with data itself 😭

Sometimes the database answered exactly what I wanted 😌
Sometimes it returned completely unexpected rows 😵‍💫
And sometimes SQL just looked at me like:

> “be more specific please.” 💀

From writing basic SELECT queries to understanding JOINS and WINDOW FUNCTIONS, this journey slowly started feeling less like “learning commands” and more like learning how data actually behaves behind the scenes 📦

There were moments like:

* “okay why are duplicate rows coming 😭”
* “wait… WHERE and HAVING are not same???”
* “OH SO THAT’S HOW PARTITION BY WORKS 👀”

And honestly, solving those tiny confusions one by one made SQL feel surprisingly addictive ✨
